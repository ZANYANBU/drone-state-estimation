The central idea

A Linear Dynamical System is a continuous HMM

Every algorithm from this unit transfers. Only the state changes — from a finite set of symbols to a vector of real numbers — and sums over states become integrals that stay Gaussian.

Viterbi has an analogue too: for a linear-Gaussian model the most likely path equals the smoothed mean.

This is the slide that ties the project to the syllabus, so spend time here. The point is that we are not doing something separate from HMMs — we are doing the same thing with a continuous state space. The forward algorithm becomes the Kalman filter. Forward-backward becomes the RTS smoother. Baum-Welch becomes EM for the noise covariances. Even the scaling factors have a counterpart: in the HMM we normalise alpha to stop underflow, and here we accumulate log-likelihood through the innovation covariance for the same reason. And Viterbi: because everything is Gaussian and therefore unimodal, the most likely single path is just the sequence of smoothed means, so Viterbi and forward-backward give the same answer here, which is not true for a discrete HMM.
